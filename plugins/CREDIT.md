## Integration

Think Deeper integrates these skills into its own browser-based agent environment.

The surrounding Think Deeper application provides functionality such as:

- Agent orchestration
- Tool calling
- Virtual filesystem
- Code workspace
- Sandboxed Python execution
- Multi-agent teams
- Automations
- Web and image search
- ONNX Runtime Web
- GitHub integration
- Memory and workspace management
- Plugin loading
- Model/provider configuration

The inclusion of a third-party skill does not mean that the third-party author endorses or officially supports Think Deeper.
