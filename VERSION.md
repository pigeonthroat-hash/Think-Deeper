# Think Deeper — Version History

Think Deeper is an agentic workspace that gives ordinary models time, tools, and self-correction.

## 🚀 Current Release — V1.0.0

**Initial public release**

Think Deeper V1.0.0 is the first official release of the project.

### 🌐 Live App

**[Open Think Deeper](https://think-deeper-app.vercel.app/)**

The live application is available directly in your browser. No installation is required.

---

## What's included

### 💬 Chat

- Streaming AI responses
- Markdown rendering
- Syntax highlighting
- KaTeX mathematical expressions
- Collapsible thought process
- Image and file attachments
- Conversation branching
- Regenerate / continue / copy / delete
- Conversation search
- Projects for grouping related chats
- Deep Think mode
- Adjustable reasoning intensity

### 🧠 Agent Mode

- Supervisor-led multi-agent teams
- Multiple specialist agents
- Team sizes up to 8 agents in higher intensity modes
- Quick Ask for smaller tasks
- Separate agent conversation history
- Live team progress

### 💻 Code Workspace

- In-browser virtual filesystem
- File creation and editing
- Automatic file version archiving
- HTML/CSS/JavaScript live preview
- Monaco Editor
- Run / Fix / Revert workflow
- Sandboxed Python execution
- Workspace file paging
- Optional external folder workspace

### 🔧 Agent Tools

The agent can use tools including:

- `list_files`
- `read_file`
- `write_file`
- `delete_file`
- `search_file`
- `run_python`
- `check_code`
- `web_search`
- `image_search`
- `generate_image`
- `run_onnx`
- `self_check`
- `ask_user`
- `show_site_options`
- `github_create_repo`
- `github_commit_files`
- `github_enable_pages`

### ⚙️ Automations

- Visual automation canvas
- Drag-and-drop nodes
- Triggers and actions
- Scheduled workflows
- User-send and AI-reply triggers
- Broadcast events
- Conditional logic
- Safe JavaScript Define blocks
- Natural-language automation builder

### ☁️ Accounts & Sync

- Guest mode
- Google sign-in
- Firebase Authentication
- Firestore synchronization
- Cloud conversation sync
- Settings synchronization
- Pins and automation synchronization
- Account profiles
- Persistent memory

### 🎨 UI

- Dark mode
- Light mode
- Multiple accent palettes
- Font themes
- Adjustable text size
- Responsive mobile layout
- 20+ language-ready localization architecture

### 🤖 Model Support

Think Deeper supports configurable AI providers, including:

- OpenAI
- Groq
- OpenRouter
- Gemini
- Custom OpenAI-compatible endpoints

The app also supports:

- Main model selection
- Model libraries
- Separate chat/code/reasoning models
- Optional fallback providers
- Image models
- Local model files
- ONNX Runtime Web

## Release numbering

Think Deeper uses semantic-style version numbers:

*MAJOR*-*MINOR*-*PATCH*

For example:

- **MAJOR** — major architectural or product changes
- **MINOR** — new features and significant improvements
- **PATCH** — bug fixes and smaller changes


The current version is a **MAJOR** update.
